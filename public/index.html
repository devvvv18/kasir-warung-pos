Pengaturan Toko & Struk

Informasi dicetak pada struk thermal printer MP-58BC.

Printer Iware RPP02N / MP-58BC (Bluetooth 58mm)

Format struk presisi 58mm (32 karakter/baris). Mendukung cetak langsung via Web Bluetooth (di Laptop/PC) & aplikasi RawBT (di HP Android).

💡 Panduan Cetak:

• Dari Laptop: Buka http://localhost:3000 di Chrome → klik tombol di atas → pilih printer → selesai!

• Dari HP Android: Install aplikasi RawBT dari Play Store → pair Bluetooth printer di HP → saat transaksi selesai tekan tombol hijau 'Cetak via RawBT'.
